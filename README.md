# 我的饮食日记（iPhone 本机版）

## 项目内容
- `index.html`：饮食、心理、身体记录与历史/分析界面
- `manifest.webmanifest`：添加到主屏幕所需的应用配置
- `sw.js`：离线缓存
- `icon-192.png` / `icon-512.png`：应用图标

## 部署与安装
1. 将本文件夹内所有文件上传到一个支持 HTTPS 的静态网站托管服务（例如 GitHub Pages、Netlify 或 Cloudflare Pages）。
2. 使用 iPhone 的 Safari 打开部署后的 HTTPS 地址。
3. 点击 Safari 分享按钮 →「添加到主屏幕」→「添加」。
4. 从桌面图标启动应用。

## 数据与隐私
- 日记通过 IndexedDB 保存在当前设备/浏览器的本机存储中。
- 应用本身不包含账号系统，也没有将日记上传到服务器的代码。
- 清除 Safari 网站数据、重置设备或更换设备可能导致本机数据丢失。请定期在「数据管理」中导出 JSON 备份。
- JSON 备份文件包含个人日记内容，请妥善保管。

## 当前版本说明
这是可运行的首版项目。趋势页目前提供记录数量及常见味道/心理/身体状态统计；后续可继续增加按日趋势图和更细致的时间关联分析。
